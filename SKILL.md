# Internship & Job Application Tracker

## Overview

The Internship & Job Application Tracker is a personal dashboard that helps users organize and track every internship or job application in one place.

Instead of managing applications through spreadsheets or searching through emails, users can record important information such as the company, position, work mode, application status, interview progress, and additional notes.

The goal is to provide a clean, simple, and efficient way to monitor every application throughout the recruitment process.

---

## Main Features

### 1. Add New Application

Users can create a new application by filling in the following information.

| Field | Description |
|--------|-------------|
| Company | Company name |
| Position | Job or internship position |
| Type | Internship, Full-time, Part-time, Contract, etc. |
| Work Mode | On-site, Hybrid, Remote |
| Location | City, Province, or Country |
| Date Applied | Date when the application was submitted |
| Status | Current application status |
| Allowance | Internship allowance or salary (optional) |
| Job Posting | URL to the original job posting |
| Notes | Additional information such as interview feedback, recruiter name, reminders, or preparation notes |

---

### 2. Status Management

Each application should have a selectable status.

Available options:

- Wishlist
- Preparing
- Applied
- Online Assessment
- Interview
- Final Interview
- Offer
- Accepted
- Rejected
- Withdrawn

Users should be able to update the status anytime.

---

### 3. Work Mode

Dropdown options:

- On-site
- Hybrid
- Remote

---

### 4. Application Type

Dropdown options:

- Internship
- Full-time
- Part-time
- Contract
- Trainee

---

### 5. Search & Filter

Users should be able to search applications by:

- Company
- Position

Users should also be able to filter by:

- Status
- Work Mode
- Type
- Location

---

### 6. Sorting

Applications can be sorted by:

- Date Applied
- Company
- Position
- Status

---

### 7. Dashboard (Optional)

Display quick statistics such as:

- Total Applications
- Applied
- Interview
- Offers
- Accepted
- Rejected

Optionally display charts showing application progress.

---

### 8. Notes

Each application can include free-text notes for recording:

- Interview experience
- Questions asked
- Recruiter information
- Follow-up reminders
- Personal reflections
